# 成员 B 长期任务手册：视觉识别与测量负责人

日常输入、输出和可复制命令统一见 [成员 B 工作流程与命令百科](成员B_工作流程与命令百科.md)。本手册负责解释长期职责、学习路线和算法升级条件。

## 1. 你的角色到底有什么用

你不是“调几个OpenCV参数的人”。你负责把A的图片变成能够被比较、被定位、被下游使用的测量结果。

```text
图片 → 污渍mask → 面积/中心/误差 → StateEstimate → 前后变化
```

你的输出是系统的“眼睛和尺子”。B测错了，C规划得再漂亮也只是在准确地处理错误位置。

## 3. 你的输入和输出

### 从A得到

- 可解码图片；
- 图片和样本ID；
- 拍摄设备、批次和条件；
- 人工标注mask；
- 质量问题和ignore区域。

### 输出给C

B不输出COM口、喷射时长或电机指令。

## 4. 当前核心任务：HSV Baseline v0

Baseline（基线）是最简单、可复现、以后用来比较升级方案的方法。

### 4.0 先处理一个当前接口债务

这个接口债务已在 `mcl-v0.1` 解决：`ContaminationMeasurement` 输出 `uncertainty_px`；经过有效标定后，`StateEstimate` 才允许出现 `uncertainty_mm`。B下一步不再写接口提案，而是用真实图片检查HSV分割和像素误差是否合理。

### 4.1 先用合成图片解除等待

在A数据到位前，由测试代码生成：

- 纯背景；
- 一个彩色色块；
- 两个独立色块；
- 带小噪点的色块；
- 位于图片边缘的色块。

合成数据只证明程序逻辑，不能证明真实污染识别有效。

### 4.2 理解最小处理链

```text
BGR图片
→ HSV颜色空间
→ 颜色阈值
→ 二值mask
→ 最小形态学去噪
→ 连通区域
→ 面积和中心
```

- BGR：OpenCV默认的蓝、绿、红通道顺序。
- HSV：色相、饱和度、明度，更适合描述“什么颜色”。
- 阈值：规定哪些颜色算候选污染。
- 形态学：对mask做小范围膨胀/腐蚀，去除孤立点或填小洞。
- 连通区域：相邻白色像素组成的独立块。

### 4.3 参数必须显式

不要在函数深处散落魔法数字。HSV上下限、最小面积、形态学核大小都放在一个策略对象中，并验证范围是否合法。

调参只使用开发图片；保留图片只能用于最后评价，不能看结果后继续调。

### 4.4 输出mask、面积和中心

第一版先明确：

- 总面积是所有有效区域面积之和，还是只取最大区域；
- 多目标时向C输出一个中心还是多个候选；
- 没有目标时中心必须为 `None`；
- 当前误差单位是像素，不是毫米。

不要使用固定 `0.01 mm/px` 等比例制造可执行坐标。

### 4.5 可视化不是装饰

在原图上绘制：

- mask边界；
- 中心点；
- 区域编号；
- 被忽略区域；
- 当前参数版本。

它的用途是让人快速发现算法是否“数值正常但位置错误”。

### 4.6 与人工标注比较

至少使用：

| 指标 | 大白话解释 |
|---|---|
| IoU | 算法区域和人工区域重叠得有多好 |
| 面积相对误差 | 算法面积比人工面积多算/少算多少 |
| 质心误差 | 两个中心相隔多少像素 |
| 假阳性 | 把背景当污染 |
| 假阴性 | 漏掉污染 |

不要只报告平均数，还要保存最差的几张图片。

## 5. 前后复检为什么归B

复检不是行政检查，而是第二次视觉测量：动作前后图是否可比较，污染面积是否真实减少。

第一版只做：

1. 检查前后图质量；
2. 对齐轻微平移；
3. 使用同一分割策略测面积；
4. 计算去除率；
5. 无法对齐或光照变化过大时返回人工判断。

当前不需要复杂损伤检测。以后只有真实样本出现可复现损伤风险，才增加对应测量。

## 6. 你的学习路线

### L0：当前必须掌握

| 知识 | 学到什么程度 | 最小练习 |
|---|---|---|
| NumPy数组 | 看懂图片形状和布尔mask | 统计mask白色像素数 |
| OpenCV颜色空间 | 会BGR↔HSV | 分离一个明显色块 |
| 阈值和形态学 | 知道参数改变会发生什么 | 对比去噪前后mask |
| 轮廓/连通域 | 能得到区域面积和中心 | 处理两个独立色块 |
| 单元测试 | 会构造已知答案的图片 | 验证面积和中心 |

### L1：P1/P2学习

- 人工标注与评价指标；
- 图像配准：把前后图对齐；
- 不确定度：结果可能偏差多大；
- 数据泄漏：测试图片不应参与调参；
- 失败分类：成像失败、分割失败和配准失败不能混为一类。

### L2：模型阶段学习

- 语义分割：给每个像素分类，比目标框更适合面积测量；
- 训练/验证/测试区别；
- 过拟合、类别不平衡、数据增强；
- 模型推理适配：无论内部算法怎样变，仍输出相同测量合同。

YOLO不一定是第一模型。若任务需要精确面积，分割模型通常比只输出矩形框更贴近问题，但必须由失败证据决定。

## 8. AI和人的边界

AI适合：生成合成图片、OpenCV代码草案、参数验证、单元测试、指标计算和错误聚类。

你必须亲自：查看mask、确认人工真值、决定多目标规则、区分成像与算法错误、判断指标是否反映任务。

绝不能让模型预测自己充当人工真值。

## 9. 常见失败与处理

| 失败 | 错误做法 | 正确做法 |
|---|---|---|
| 反光被识别成污染 | 针对单图无限调阈值 | 保存失败，反馈A并设计独立验证 |
| 多个污渍中心不合理 | 静默取平均 | 明确多目标策略并测试 |
| 前后面积变化很大 | 直接写清洗成功 | 先检查配准和光照可比性 |
| 模型指标高 | 放弃简单基线 | 同一独立测试集做A/B |
| 没有标定 | 输出毫米中心 | 只输出像素结果并停止动作链 |
