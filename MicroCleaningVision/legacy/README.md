# 旧版原型区

这里保存项目早期按硬件/工具划分的代码和测试，包括相机、检测、规划、通信、3D 与训练设想。它们被保留是为了选择性迁移和理解历史，不是当前可运行能力。

## 为什么不在当前主线

- 多个关键方法仍是 `pass`（空实现）。
- 旧主程序曾让规划结果直接进入移动/喷射，没有当前安全合同。
- 旧测试依赖缺失且与部分接口不匹配。
- 双视角、YOLO 和 3D 没有项目数据或实验结果支持。

## 迁移规则

1. 先在 `microcleaning/` 中明确新接口和负责人测试。
2. 只提取解决当前任务的最小逻辑，不整体复制目录。
3. 用真实图片或可复现测试验证后，才在 `project_state.yaml` 增加能力。
4. `legacy/` 中的代码不得被 `main.py` 或当前 `microcleaning/` 导入。
