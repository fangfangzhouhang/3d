## 2. P1：喷头模型与证据

`FootprintProfile(profile_id, diameter, unit, evidence, conditions, shape, semantics, version, parent_sha256)`：

- `diameter` 必须显式传入；未知可填 `None`，不会回退到旧演示半径。单位仅 `px` 或 `mm`；已知值必须为有限正数，bool 不当数字。
- `Evidence(status, source_ref, sha256=None)` 的状态是 `assumed` / `measured`，来源不能为空。软件不认证实测档案的真实性；如有原始文件，调用者应填写 SHA256。
- 实测 Profile 仅支持 `wet_footprint` 语义，必须提供 `SprayConditions` 的喷头编号、高度 mm、介质、试片、时长 ms、供给条件。湿润足迹仍不等于污染清除效果。虚拟几何模型使用 `geometric_proxy`。
- `PixelScale(mm_per_px_x, mm_per_px_y, evidence, image_shape_hw=None)` 独立记录尺度证据。mm 圆盘在非等比例尺度下成为像素椭圆。若绑定图像尺寸，输入 Mask 必须同尺寸；本版本不建模透视/畸变变化。
- `build_kernel(profile, scale=None) -> KernelResult`：按整数像素中心落在闭圆盘内建立 bool 核，计数来自实际栅格，不用 πr² 冒充离散面积。mm 模型缺尺度时不可用。
- `FootprintKernel` 可接收显式二值核和 `(x,y)` 锚点；元数据区分 `explicit_binary_mask` 与圆盘工厂的栅格规则，保留核形状、锚点、Mask/Profile/尺度哈希。
- `profile.with_diameter(new_diameter)` 返回新快照。修改实测值时，新快照自动标为 assumed，并保留父 Profile 哈希；原实测 Profile 不变。

动态直径调整需重新 **构建核 → 约束候选 → 贪心规划 → 覆盖指标**。输入 Mask 和来源快照、消费者的字段结构不用改变。P3/P4 将据此重绘、取消旧请求，当前未实现滑条或 UI。

不可用原因包括 `FOOTPRINT_DIAMETER_MISSING`、`PIXEL_SCALE_MISSING`、`FOOTPRINT_SHAPE_UNSUPPORTED`、转换越界及核资源上限。接口格式错误、非有限值或不合法单位抛 `ValueError`，与“合法配置但当前条件不足”区分。

## 3. P2：完整 Mask 与贪心规划

`CoverageInput(mask, target_id, mask_kind, source_ref, frame_id=None, image_ref=None, image_sha256=None, segmentation_sha256=None)`：

- Mask 为非零尺寸二维 numpy bool 或 uint8，uint8 仅允许 0/1/255。输入被规范化并复制到只读快照；浮点概率、RGB、其他灰度值被拒绝。
- 坐标为原图像素，`shape_hw=(height,width)`，驻点/锚点为 `(x,y)=(列,行)`。没有隐式 ROI 平移或物理平台坐标转换。
- `mask_kind` 明确区分 `segmented_stain`、`manual_region`、`manual_roi_segmented`、`synthetic`、`reference_annotation`。填满的人工矩形保留 `area_kind=manual_region_px`；区域覆盖比例不能解释为真实污渍覆盖率。
- 算法从完整传入 Mask 计算增益，不做“最大连通块”筛选。小残片参与目标总面积，但较低目标覆盖率或驻点预算仍可能留下它，遗漏 Mask 会保留。
- **调用者必须提供完整目标 Mask。** 本轮没有修改旧 `cleaning_loop` 中最大残片执行选择，也没有让工作台开始供应新输入。未来适配应在筛选前冻结完整原尺寸 Mask，并绑定首次图像/分割哈希；不能从 centroid/bbox 还原真实分割。

`CoveragePolicy(target_coverage=0.95, max_stations=64, candidate_stride_px=1, start_px=(0,0), coverage_basis="nominal")`：

- 起点是图内的虚拟路线参考点，不代表硬件位置。候选为图内固定网格，可位于污渍外；网格步长影响可达到的覆盖率。
- 每轮最大化未覆盖目标像素增益；相同增益先选离前一驻点最近的点，再按 y、x 升序。驻点序列可重复，无随机数或时间戳。
- 达到目标覆盖率、驻点预算耗尽、无候选或无新增覆盖即停止。选择顺序也是展示访问顺序；尚未做二次路线优化。
- 贪心不是全局最优/连续空间最优。距离为像素直线连线长度，包含虚拟起点到首点；它不是当前双轴固件实际轨迹、脉冲数或行程安全验收。

`CoverageConstraints(allowed_centers_mask=None, allowed_spray_mask=None, forbidden_mask=None, evidence=None, position_uncertainty=None)`：

- True 分别表示允许驻点、允许喷湿、禁止喷湿；禁喷 Mask 优先。所有约束 Mask 必须同输入尺寸，提供 Mask 时必须提供来源证据。
- 整个足迹必须落在允许喷湿域，不能仅凭中心安全放行。图外永远视为禁止，边界污渍可能不可完全覆盖；明确返回 PARTIAL 和遗漏。
- 未提供域时仅以图像范围做模拟，warnings 明确标记默认域/安全证据/定位误差未知；这些像素域不替代物理行程、碰撞或限位约束。
- `PositionUncertainty(radius, unit, evidence)` 支持 px/mm，零误差也须显式声明；mm 误差需要尺度。x/y 误差向外取整成轴对齐离散像素盒，扩大足迹检查喷湿安全，同时收缩足迹计算条件下的保守覆盖。
- `coverage_basis="conservative"` 使用收缩核做贪心与停止判断；无定位误差模型时返回 CONSTRAINTS_UNAVAILABLE。nominal 方案仍可报告其保守覆盖。未提供误差时保守指标为 None。
- 此误差盒是条件下的离散保守近似，会牺牲可行性；它不证明实际定位误差受约束，也不建模喷痕边界变化、遮挡、供水波动或污染粘附。

## 4. 结果、指标和失败语义

`plan_coverage(input, model, *, policy=..., constraints=None) -> CoveragePlan`：

- `stations` 保存编号、xy、nominal 新增覆盖面积、目标增益和两种累计覆盖比例；`points_px` 返回访问坐标。
- `evaluation` 包括 footprint/covered/uncovered/overlap bool Mask、uint32 覆盖次数图、可选保守覆盖 Mask。所有返回数组为只读快照。
- `to_dict()` 返回 JSON 可序列化的模式版本、确定性 plan_id、输入/Profile/核/约束哈希、参数、状态、原因、驻点、指标和 Mask 元数据。**没有写文件、PNG、图像叠加或 UI 动作；Mask 像素数组仍在内存，JSON 元数据不代替可重放的数组文件。** 完整归档由后续 P3 设计。
- `executable=False` 是不可在构造/replace时改为 True 的冻结字段；字典还固定 `feeds_action_request=False`、`send_to_controller=False`。不转换为旧执行请求，未导入执行/串口模块。

设目标 Mask 为 M，所有驻点的离散喷湿并集为 U：covered=M∩U，uncovered=M\U，比例为 |covered|/|M|。空目标比例为 None。

| 指标 | 定义 |
|---|---|
| target/covered/uncovered_area_px | 完整目标、预计覆盖、遗漏的像素计数 |
| geometric_coverage_rate | 预计几何覆盖比例；绝不命名或宣称实际清除率 |
| footprint_area_px | 全部足迹并集，包括图外像素 |
| outside_target_area_px | 足迹并集减目标内覆盖，含图外部分 |
| outside_image_area_px | 图外足迹并集面积；评估已有驻点时可非零，合格规划应为零 |
| overlap_target_area_px | 目标内被至少两个驻点覆盖的像素，重复驻点按次数计 |
| conservative_covered_area_px/rate | 显式误差盒条件下的保守覆盖；缺误差模型为 None |
| target/uncovered_area_mm2 | 显式 x/y 尺度换算的面积；无尺度为 None，仍带尺度证据 |
| station_count / route_length_px | 驻点数 / 几何访问连线距离 |

状态：COMPLETE 仅表示选定模型和目标比例满足；PARTIAL 保留真实几何遗漏。NO_TARGET、MODEL_UNAVAILABLE、CONSTRAINTS_UNAVAILABLE、RESOURCE_LIMIT、METRICS_UNAVAILABLE 记录原因；无可用评估时 metrics/Mask 为 None，不提供漂亮百分比。格式/尺寸错配抛 ValueError。

当前软件资源上限：输入 1,000,000 像素，核/误差展开核 262,144 单元，候选 250,000 个，规划最多 256 驻点，评估最多 4,096 点及 4,000,000 单元画布。它们是计算保护，不是机械安全边界。大图可显式降低候选密度，当前没有实时性能承诺。

## 5. 可运行的离线例子

在项目目录和已安装 numpy/OpenCV 的 Python 环境中执行；例中尺寸是主动选择的合成情景，没有真实喷头默认尺寸。

```python
import json
import numpy as np
from microcleaning.control_system.planning.coverage_model import Evidence, FootprintProfile, build_kernel
from microcleaning.control_system.planning.coverage_planner import CoverageInput, CoveragePolicy, plan_coverage

mask = np.zeros((31, 49), dtype=np.uint8)
mask[8:18, 8:25] = 255
mask[23:25, 38:40] = 255  # 保留另一块小残留
source = CoverageInput(mask, "demo-target", "synthetic", "example:full-mask")
profile = FootprintProfile("virtual-circle", diameter=6, unit="px",
    evidence=Evidence("assumed", "example:user-selected-diameter"))
plan = plan_coverage(source, build_kernel(profile), policy=CoveragePolicy(target_coverage=1))
print(json.dumps(plan.to_dict(), ensure_ascii=False, allow_nan=False))
print(plan.points_px, plan.metrics.geometric_coverage_rate, plan.executable)

larger_profile = profile.with_diameter(10)
larger_plan = plan_coverage(source, build_kernel(larger_profile), policy=plan.policy)
print(larger_plan.points_px, larger_plan.metrics.geometric_coverage_rate)
# 原 source 和 profile 没有被修改；重新计算核、规划和指标。
```
