# 硬件组说明：从接线到第一次软硬件联调

> 硬件组从这一个文件开始，不需要先读 A、B、C 的全部代码。

## 1. 我们共同要做出的第一个结果

第一阶段不追求自动 XY 扫描，也不追求工业级设备。双方先共同完成：

```text
电脑发送 PING
→ NUCLEO 返回 PONG
→ 电脑读取急停和水泵状态
→ PB5 能控制 MOSFET
→ 在人工确认下完成一次有时长限制的水泵短脉冲
→ NUCLEO 返回 ACK / DONE / ERR
```

这条链跑通后，软件识别结果才有一个真实、明确的硬件出口。

## 2. 整个项目怎样连接

```text
U500 USB数码显微镜
        │ USB，只接电脑
        ▼
电脑端 A：保存图片和检查质量
        ▼
电脑端 B：输出污染 Mask、面积、中心
        ▼
电脑端 C：生成 ActionRequest（动作申请）
        ▼
电脑端 STM32 协议适配
        │ ST-LINK VCP / USB 串口
        ▼
NUCLEO-F401RE
        ├── PB5 → MOSFET → 12V 水泵
        └── PB12（CN10-16）← 急停状态
```

关键说明：

- U500 是 USB 数码显微镜，不是工业相机；它直接连接电脑，不连接 NUCLEO。
- `D4 = PB5`；但 `D12 = PA6`，不能把 D12 写成 PB12。
- 本项目使用的 `PB12` 位于 Morpho 排针 `CN10-16`。
- 图像、Mask 和规划都在电脑端完成；NUCLEO 只执行格式固定、范围有限的命令。

## 4. 软件组已经交付给硬件组的代码

| 文件 | 硬件组怎样使用 | 当前边界 |
|---|---|---|
| `microcleaning/control_system/stm32_protocol.py` | 对照它实现相同的协议文本 | 只编码和解析，不打开串口 |
| `scripts/probe_stm32_link.py` | 固件完成后检查 `PING/STATUS` | 不发送水泵或移动命令 |
| `microcleaning/ports.py` | 理解未来真实控制器的输入和输出 | 不要求 STM32 使用 Python |
| `microcleaning/control_system/fake_serial.py` | 了解电脑端当前怎样模拟回执 | 模拟结果不是硬件证据 |

硬件组不需要把这些 Python 文件复制进 CubeIDE。双方只需要遵守同一份协议。

## 5. 硬件组需要交回什么

### 第一批：接线和器件事实

- 水泵型号、额定电压、额定电流；
- MOSFET 模块正反面照片或购买链接；
- MOSFET 输入是高电平启动还是低电平启动；
- 急停按钮是一组 NC 还是两组独立 NC；
- 12V 电源额定电流；
- 保险丝 F1/F2 的实际值；
- 实际接线照片和接线图版本号。

### 第二批：STM32 固件证据

- 能在 STM32CubeIDE 中重新编译的真实工程；
- `.ioc`、`.c`、`.h` 和工程配置；
- `PING → PONG` 串口记录；
- `STATUS` 在急停按下/松开时的两组输出；
- PB5 默认关闭以及开关测试结果；
- 已实现命令和未实现命令列表。

### 第三批：机械参数，第二阶段再交

- 托盘有效宽度、高度，单位 mm；
- X/Y 最大行程、原点方向和限位位置；
- X/Y 每毫米步数和最大速度；
- 相机中心到喷头中心的偏移；
- 水泵允许的最大单次开启时间。

这些数值没有实测前，软件不会建立假的机械配置。

## 6. 为什么现在不提前创建固件框架

仓库当前不会提前生成空的 `firmware/nucleo_f401re/Core/...`。原因很直接：真实工程名、CubeMX 版本、HAL 配置和目录应由真正编译过代码的人决定。

硬件组第一次上传时创建：

```text
firmware/
└── nucleo_f401re/
    └── <真实CubeIDE工程>/
```

这样不会与空壳工程冲突，也不会出现“目录存在但固件不能编译”的假完成。

## 7. 当前完成和未完成

### 已完成

- U500 的电脑端通用 USB 采集适配器已经过无硬件测试；
- 最小串口协议的电脑端编码和解析已建立；
- `PING/STATUS` 探测入口已建立；
- 软件 FakeSerial 能模拟回执。

### 未完成

- U500 实机抓图仍需在团队电脑上验证；
- NUCLEO 固件尚未进入本仓库；
- 串口协议尚无实机 `PONG/STATUS` 证据；
- 真实水泵、急停、MOSFET 和 XY 都未完成软件联调。

因此当前只能说“接口准备完成”，不能说“硬件闭环完成”。
