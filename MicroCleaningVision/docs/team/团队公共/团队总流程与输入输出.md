# 团队总流程与输入输出

## 1. 项目总体输入和输出

这个项目不是“输入图片，输出一个好看的识别框”。长期要解决的是：机器看到表面状态，提出受限处理动作，执行后再次观察，并用证据判断是否真的改善。

### 当前软件阶段的总体输入

```text
一张 JPG/PNG 图片
+ 图片来源和采集条件
+ A 制作的人工 Mask（只用于评价，不用于 B 推理）
```

### 当前软件阶段的总体输出

```text
B：算法 Mask、污染面积、污染中心、算法版本
C：像素坐标中的目标点、处理策略、路径图
系统：summary.json 和 Episode
```

当前输出只是“软件分析和像素路线”，不是 STM32 可执行的真实清洗命令。

### 长期硬件闭环的总体输出

```text
动作前状态 State_t
+ 实际执行动作 Action_t
+ 动作后结果 Outcome_t+1
+ 成功/重试/人工处理结论
```

这组 State–Action–Outcome 才是未来训练结果预测、自动选参数和 Robot Memory 的数据基础。

## 2. 三人的数据接力

| 环节 | 负责人 | 输入 | 实际处理 | 输出 | 交给谁 |
|---|---|---|---|---|---|
| 数据准备 | A | 手机、USB显微镜或合法公共图片 | 质量检查、metadata、人工标注 | 原图、人工JSON、人工Mask、质量说明 | B |
| 视觉识别 | B | 原图；开发阶段可看人工Mask分析误差 | HSV或未来分割模型 | 算法Mask、面积、中心、置信信息、算法版本 | A评价、C规划 |
| 独立评价 | A | 人工Mask、B算法Mask | IoU、面积误差、中心误差 | 评价JSON和失败类型 | B |
| 路径规划 | C | B算法Mask和像素测量 | 选策略、生成目标点和分段路线 | 路径点、路径图、像素坐标计划 | 软件Demo；未来标定模块 |
| 坐标标定 | C与硬件接口协作 | 像素点、真实标定点 | 像素到毫米变换和误差检查 | 带标定版本的毫米目标 | ActionRequest |
| 真实执行 | 未来STM32/机构团队 | 经批准的结构化动作 | 电机、泵、平台确定性控制 | ExecutionReceipt | 视觉复检 |
| 动作后复检 | B，A提供数据规范 | 动作前后图片 | 对齐、再次分割、残留比较 | VerificationResult | 团队决策 |

一句话记忆：

> A 出题并制作人工参照，B 在不偷看答案时识别，A 判卷，C 把 B 的结果变成路线；硬件执行后，B 再看一遍是否真的处理成功。

## 3. 哪些输入不能混用

### B 推理时可以使用

- 原图像素；
- 已冻结的算法参数；
- 明确允许的采集条件。

### B 推理时不能使用

- 当前图片对应的人工 Mask；
- 人工写下的污染中心；
- 为了让结果好看而临时修改的答案。

人工 Mask 是评价答案，不是算法输入。开发图片的答案可以帮助 B 分析失败；留出图片的答案必须等参数冻结后再评价。

### C 应该使用

- B 的算法 Mask；
- B 的面积、中心、算法版本和坐标单位。

C 不应该使用人工 Mask 代替 B 的输出，否则只能证明规划程序能吃“正确答案”，不能证明真实软件链路已经接通。

## 4. 顺序任务和并行任务

### 必须顺序交接的主链

```text
A原图 → B算法Mask → C像素路线
A人工Mask + B算法Mask → A评价 → B改进
```

### 不等待上游也能做的并行任务

- A：继续采集、标注、检查数据来源，建立开发图和留出图；
- B：使用合成图片完成空目标、单目标、多目标、噪点和边界测试；
- C：使用合成 Mask 完成空路线、小区域、大区域和断开区域测试。

因此某个人临时没有完成任务，不应该导致另外两人完全停工。

## 6. 总体交付检查

一张图片完成当前软件闭环，至少要有：

```text
[ ] 原图和来源记录
[ ] 人工Labelme JSON
[ ] 人工Mask并经人复核
[ ] B算法Mask
[ ] B面积、中心和算法版本
[ ] A的IoU/面积误差/中心误差
[ ] C像素路径和可视化
[ ] summary.json或Episode
[ ] 明确写出仍未完成真实标定和硬件执行
```

## 7. 当前最重要的边界

- 图片质量分数用于自动体检和失败诊断，不是未经标定的淘汰标准。
- 网上图片可以练习软件链路，但不能冒充USB显微镜实验数据。
- 像素坐标不能直接当毫米坐标。
- `simulate` 和 FakeSerial 不会打开真实 COM 口，也不证明清洗成功。
- 真实动作结束后必须再次拍照复检，才能称为闭环。
