# 最小闭环（MCL）路线图：从“还不知道”到“有真实证据”

MCL 是 Minimum Closed Loop 的缩写。它不是“大系统的简化演示”，而是一条能独立回答“看到了什么、为何允许动作、设备是否真的执行、结果是否复查”的最短真实链路。

## 先理解 P1 任务卡

下表的“未设定”不是欠缺文档，而是在提醒团队：这些物理事实必须由真实成员测量、讨论并签字，不能让代码或模型替我们猜。

## P1 任务卡 — 物理工作前需人工关卡

| 字段 | 当前值 |
|---|---|
| 任务 ID | `P1-MCL-BASELINE-v0` |
| 样品/材料 | **未设定 — 需人工决策** |
| 污染类型/协议 | **未设定 — 需人工决策** |
| 相机 | 单一固定俯视；实际型号/参数未设定 |
| 检测基线 | 真实图像基线后的阈值/OpenCV，默认非 YOLO |
| 动作原语 | 单个有界 `SPRAY_AT_POINT`；物理时长/压力未设定 |
| 验证 | 相同成像条件；残差与损伤指标未设定 |
| 重试 | 仅在真实基线定义风险后最多一次；否则人工 |
| 成功 | **未设定 — 需预先登记的物理阈值** |
| 停止 | 急停(E-stop)、联锁/通信/标定故障、低质量、超出工作空间、疑似损伤 |

## 最短证据路径：不要跳过中间台阶

1. **冻结任务卡。** A、B、C 各选择一个安全的样品、污染、液体以及成功/损伤判据。
2. **A E1：** 用固定俯视相机、照明、曝光、放大率与不可变 ID 采集十张装调验证图像。记录对焦/照明验收规则。
3. **A+C E1：** 创建相机到工作平面的标定记录，包含坐标系、单位、目标误差、日期与失效规则。不得从未测量的数字设定动作限值。
4. **B+C E1：** 在空运行中验证安全停止、E-stop、工作空间边界、联锁、控制器协议与实际值回执。不涉及 AI。
5. **A+B+C E2：** 通过完整契约运行一次物理无液体/干运动，并比较请求位姿与实际位姿。
6. **全体 E3 候选：** 开展 20 次受控真实回合，保留成功与失败案例；审查证据是否满足既定的 P1 停止/成功规则。

## “高级”模块什么时候才有资格出现

下面不是技术愿望清单，而是淘汰机制：如果一项技术没有解决当前已记录的失败，或 A/B 对照没有净收益，就不该留在主线。

| 候选 | 仅在以下条件下启动 | 仅在以下条件下保留 |
|---|---|---|
| YOLO/CNN | 固定基线感知失败反复出现 | A/B 改善项目相关检测与端到端成功率 |
| 第二视角 | 已记录遮挡/反射/定位失败 | 净收益超过标定、延迟与维护成本 |
| Z / 3D / 旋转 | 表面高度/几何导致测得的未命中/失焦失败 | A/B 实质性地改善所声明的 KPI |
| 结果模型 / 记忆 | 已存在带版本的真实回合 | 它在不过度削弱安全的前提下改善有界选择 |

本计划中没有任何阈值是物理验收值；它们必须经过测量与批准。
