-----

No board was energized from 12 V, and no pump or liquid path was connected. This report
is not a 12 V authorization. 全部签字前禁止连接 12 V.

Deterministic Zig-cache test
----------------------------
`tests/firmware.test.mjs` now makes a temporary local archive containing a
version probe, injects its archive path, SHA-256 and tools directory into
`bootstrap-zig.ps1`, and starts from an invalid cached version. The bootstrap
script must replace that cache and confirm version 0.16.0. Routine tests no
longer perform a real network redownload. Production bootstrap defaults remain
the official Zig URL and official archive SHA-256 above.

Limitations
-----------
The checked-in `.ioc` and C sources were inspected and host-tested only. Target
compilation is unavailable on this machine; therefore there is no target
binary, no flashing result, and no hardware or 12 V evidence in this report.
