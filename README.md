# 微觅智造——微纳3D打印聚焦显影技术开拓者

> 仓库代号 MicroCleaningVision（原名「显微智能自清洗科研平台」为早期命名，沿用至代码与目录名；课题本义见下方更正，不要按字面理解为清洗去污项目）。

项目在 [`MicroCleaningVision/`](MicroCleaningVision/)。当前实验链是：抓一帧，识别待处理区域，规划路径，经串口发给 STM32F103，驱动 X/Y 步进电机。喷射是另一份固件，不和步进同时烧、不同一次发送。

## ⚠️ 任务定义更正（2026-11-07，负责人确认方向，工艺细节待指导老师复核）

本项目对外课题为「微觅智造——微纳3D打印聚焦显影技术开拓者」。**本项目要做的不是去除外来污渍，而是微纳 3D 打印的后处理显影工序**：要去除的是打印件自身未固化 / 未显影的材料，要保护的是已固化结构；成功标准是结构按设计文件恰好显现（该显的显出、不该动的尺寸不变），不是洁净度最大化。显影有两种互相对立的失败：欠显（未显影材料残留、沟槽 / 通道不通）与过显（已固化细结构被溶蚀、溶胀、变形）。处理剂量（浓度 × 时间 × 流量）是工艺参数，不是越强越好。

仓库历史文档与代码中的 `contamination` / 污染 / 清洗 / 去除率等说法，来自第一验证场景的**代理实验口径**（PLA 平面试片 + 可清除模拟污染），只是先用替身场景跑通「识别—受限动作—作用—复检」链条，**不是课题本义**。阅读旧文档时：设备层事实（平台、运动、安全关卡、标定、对焦、证据等级）继续有效；凡把任务目标表述为「找污渍、洗干净、去除率达标」的内容，一律按本节更正理解。历史实验记录保留原文、不追改；代码标识符（如 `contamination` 字段名）本轮不改名，读作「待处理区域」。

仍待指导老师确认、不得自行写定的事项：打印工艺类型与材料、显影液成分、未显影材料的确切形态与判定方法、合格显影件的规格（尺寸容差、通畅判据）。确认前，本节是当前工作定义，不是已核实的工艺规范。详见 DECISIONS 的 D-017 与《项目术语与概念词典》第 0 节。

在 `MicroCleaningVision` 目录下，只抓图、分析和保存双轴路径预览：

```powershell
.\.venv\Scripts\python.exe -m demo.demo_pipeline --from-camera --mode analyze --stage2-xy --camera-index 0
```

`analyze` 不打开运动串口；不能与 `--arm-stage2-xy` 组合。真实运动使用 `stage2-move`，须具备尺度 JSON、人工零点、运动关卡、现场确认和显式武装，步骤见当前总流程。普通分析预览的毫米仍是 0.01 mm/像素占位，不能写成已标定。
