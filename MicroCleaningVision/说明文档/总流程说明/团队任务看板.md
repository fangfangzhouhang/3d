#### 先学习什么

1. 图像分辨率：图片横向和纵向有多少像素。
2. 对焦与工作距离：镜头到样本距离怎样影响清晰度。
3. 采集批次：不同时间重新摆放后的一组图片，不能把连续帧当独立实验。
4. 数据清单：每张图片对应的说明表，不是简单文件列表。
5. 多边形标注：沿污渍边缘点击，得到人工参考区域。

#### 具体步骤

1. 给样本编号，例如 `pla_001`。
2. 固定显微镜、样本方向和照明；拍一张整体装置照片。
3. 记录分辨率、倍率档位、工作距离、光源档位和使用软件。
4. 第一批先拍至少12张：干净、明显污渍、小污渍各若干。
5. 至少分两次重新打开软件/重新放置样本，批次编号不能相同。
6. 保留一张失焦、一张反光、一张过曝失败图。
7. 按 [成员A工作流程与命令百科](../成员A/成员A_工作流程与命令百科.md) 运行质量检查、数据审计和metadata登记。
8. 核实来源、设备、批次、倍率和标注状态；不知道的字段保持 `unknown`。
9. 使用 Labelme 对5张图片画 `contamination` 区域；第一轮不建立多类别。
10. 运行A测试，确认迁移后的模块仍正常。

#### AI可以做什么

- 生成清单模板和自动命名程序；

### B-P1-01｜合成色块上的HSV最小识别器

| 字段 | 内容 |
|---|---|
| 类型 | 核心任务；不依赖A |
| Git分支 | `feat/b-hsv-baseline-v0` |
| 目的 | 证明B能从像素得到污渍区域、面积和中心 |
| 修改目录 | `microcleaning/vision/`、`test/vision/` |
| 输入 | 程序生成的彩色背景、单色块、多色块和噪点图片 |
| 输出 | mask、area_px、centroid_px、可视化图片、测试 |
| 任务大小 | 10点 |

#### 先学习什么

1. BGR与HSV：两种描述颜色的坐标方式；HSV更方便按颜色范围筛选。
2. 阈值分割：满足颜色范围的像素设为白色，其余设为黑色。
3. Mask：与原图同位置对应的黑白污染区域图。
4. 轮廓/连通域：把相邻白色像素组成一个区域。
5. 质心：一个区域的平均位置，可作为第一版目标中心。
6. 假阳性/假阴性：把背景误认成污渍/漏掉真实污渍。

#### 具体步骤

1. 在B测试中生成纯色背景和一个明显彩色色块。
2. 编写显式的HSV参数对象，不把阈值散落在函数内部。
3. 完成BGR到HSV转换。
4. 生成二值mask。
5. 去除非常小的孤立噪点，但不要使用过强处理改变真实边界。
6. 计算总面积和一个明确的目标中心。
7. 把mask边界和中心画回原图。
8. 增加空白、单污渍、两污渍、小噪点和非法阈值测试。
9. 输出必须进入经B-P0-01确认的 `ContaminationMeasurement`，不得直接生成动作。
10. A数据到位后，选择开发图片调参，再用保留图片测试。

#### AI可以做什么

- 生成OpenCV实现草案和合成测试图片；
- 解释HSV范围、形态学和轮廓；
- 生成边界条件测试；
- 计算与人工mask的IoU和面积误差。

#### 人必须做什么

- 看可视化结果是否真的覆盖污渍；
- 决定多个区域如何处理；
- 区分算法错误与A的成像错误；
- 保存调参失败样本，不能只展示成功图。

#### 验收证据

- 空白图不产生污染；
- 合成色块面积和中心在预期误差内；
- 多目标规则写清；
- 非法参数被拒绝；
- 至少5张结果图；
- 在A的真实图片上运行一次并记录失败；
- B测试通过。

#### 先学习什么

1. 图像坐标：左上角通常是 `(0,0)`，x向右、y向下。
2. 工作坐标：机械平台使用的物理坐标，通常以毫米为单位。
3. 标定：用已知对应点建立图像坐标和工作坐标之间的关系。
4. 目标点：计划处理的位置，不等于已经执行。
5. 路径规划：决定多个目标点的访问顺序，第一版只需要简单、可解释。
6. Dry Run：只显示和模拟动作，不驱动真实设备。

#### 具体步骤

1. 在C测试中生成一个圆形mask，不等待B。
2. 第一版先使用区域中心作为一个目标点。
3. 对多个独立区域分别产生目标点。
4. 使用最近邻或从左到右的简单规则排序，不上复杂优化算法。
5. 在图片上画目标点编号和连线。
6. 无目标时输出空计划，不生成动作。
7. 输入点超出图像范围时拒绝。
8. 接入现有 `ActionRequest` 时明确坐标单位；像素点不能冒充毫米点。
9. 运行现有FakeSerial成功/超时测试，理解申请、批准和回执的区别。
10. B输出到位后，用真实mask替换合成mask跑一次。

#### AI可以做什么

- 生成目标点选择、简单排序和画线程序；
- 编写圆形、矩形、多区域测试；
- 解释仿射变换、串口帧和ACK；
- 生成FakeSTM32异常场景。

#### 人必须做什么

- 决定目标点是否覆盖任务需要；
- 识别坐标系和单位；
- 确认路线图符合直觉；
- 不编造真实STM32协议，不打开COM口试错。

#### 验收证据

- 圆形、矩形、多区域都能生成目标点；
- 无目标时无动作；
- 目标点均在图像范围内；
- 路线图能看懂先后顺序；
- 至少一个B格式的样例mask可以直接使用；
- C测试通过；
- 明确写“像素级控制仿真，不是硬件执行”。

- 运行并解释现有FakeSerial测试；
- 画出像素坐标与工作坐标差别；
- 准备标定算法的已知点对测试；
- 不实现真实串口。

## 6. 第一轮集成卡

### TEAM-P1-INT-01｜真实图片穿过A、B、C

| 字段 | 内容 |
|---|---|
| 前置条件 | A至少交付1张合格图片；B能输出mask；C能接受同尺寸mask |
| 操作顺序 | A提供相对路径 → B输出mask/面积/中心 → C画目标点/路线 |
| 负责人 | 各自修复自己的模块；不得由C统一代改 |
| 验收 | 一条命令或三个明确命令可复现；中间文件可追溯；失败位置明确 |

集成失败怎样退回：

- 图片无法解码、条件不清 → A；
- mask错误、面积或中心错误 → B；
- 目标点、路线或动作错误 → C；
- 契约字段不足 → 单独提交共享接口提案。
