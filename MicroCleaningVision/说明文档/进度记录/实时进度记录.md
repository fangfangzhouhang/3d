# 实时进度记录

新的一条写在最上面。只记已经发生的事：小改动、现场试出来的结果、阶段性成果。计划仍放任务看板，事实边界仍以 `project_state.yaml` 为准。

## 怎么记一条

复制下面这块，改日期和内容，贴到「记录」最上方：

```markdown
### 2026-09-26　一句话标题

- 做了什么：
- 结果：
- 还没证明什么：
- 图：见下方插图；没有图就删掉这一行
```

日期用当天。同一个人同一天可以写多条，标题分开即可。

## 怎么插图片

1. 把照片放进本目录下的 `进度图片/`。
2. 文件名以日期开头，例如 `2026-09-26-继电器接线.jpg`。png、jpg 都可以。
3. 在当天那条下面写一行：

```markdown
![继电器接线，空闲时应断开](进度图片/2026-09-26-继电器接线.jpg)
```

方括号里写这张图在说什么，这样不看图也能知道它证明哪一步。一张条目可以连放多张。图片和这条 Markdown 一起提交，换电脑打开仍能看到。
