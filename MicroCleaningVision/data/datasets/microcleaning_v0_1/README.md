# MicroCleaning Dataset v0.1

## 这个目录保存什么

```text
microcleaning_v0_1/
├── raw/             # 手机或USB显微镜原图；默认不进入Git
├── annotations/     # 人工标注，建议保存Labelme JSON和导出的mask
├── metadata.csv     # 图片身份、来源、采集批次、条件和标注状态
└── README.md
```

当前状态是“数据集结构已建立，真实记录数为0”，不能写成已经拥有50张数据。

## 推荐采集顺序

1. 先导入1张图片并运行Demo，确认路径和环境正确。
2. 第一关收集12张，至少分两个重新摆放/重新启动的采集批次。
3. 保留失焦、反光、过曝等失败图，不只保存好看的结果。
4. 扩展到50张，并为至少10张制作人工污染mask。
5. 不要把同一视频连续帧拆到训练集和测试集两边。

## 导入和检查

命令见项目根目录 `README.md` 的“数据集入口”。导入工具根据文件内容生成SHA-256，重复内容不会再次复制；如果原图后来被替换，`check`会报告哈希不一致。

## 字段中不知道的内容怎么办

明确写 `unknown`，不要猜测倍率、光照或污染类型。未知事实仍然可以后补，虚构事实会污染后续实验。
