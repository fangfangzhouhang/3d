# 团队文档导航

这里按“团队公共、成员 A、成员 B、成员 C”分类。新成员先看公共总流程，再进入自己的目录；不要从代码文件猜任务。

## 先读这四个入口

1. [团队总流程与输入输出](团队公共/团队总流程与输入输出.md)：先看懂整个项目怎样从图片走到路径和未来硬件。
2. [成员 A 工作流程与命令百科](成员A/成员A_工作流程与命令百科.md)：图片、质量、标注、人工 Mask 和算法评价。
3. [成员 B 工作流程与命令百科](成员B/成员B_工作流程与命令百科.md)：原图到算法 Mask、面积和中心。
4. [成员 C 工作流程与命令百科](成员C/成员C_工作流程与命令百科.md)：算法 Mask 到像素路线、软件仿真和未来 STM32 接口。

## 两类文档为什么分开

- `任务手册`：解释角色为什么存在、长期阶段、要学习什么、不能越过什么边界。
- `工作流程与命令百科`：给出今天实际使用的输入、输出、命令、目录和交接检查。

遇到“我为什么做这个”看任务手册；遇到“下一条命令是什么”看命令百科。
