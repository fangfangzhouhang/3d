## 2. 必须修正的引脚名称

```text
D4  = PB5       可用于当前 MOSFET 控制计划
D12 = PA6       不是 PB12
PB12 = CN10-16  当前急停状态输入计划
```

简略图中的 `D12（PB12）` 必须改为 `PB12（CN10-16）`，否则实际会接到 PA6。

## 3. 第一版建议接线逻辑

### 控制信号

```text
PB5
→ 100Ω 串联电阻
→ MOSFET IN

MOSFET IN
→ 100kΩ 下拉
→ 功率地
```

真实 MOSFET 模块可能已经有输入电阻，最终仍以模块型号和端子说明为准。

### 12V 水泵

```text
12V+
→ 主保险 F1
→ 急停主触点 S1A（NC）
→ 水泵支路保险 F2
→ MOSFET / 水泵
→ 12V-
```

水泵正负极必须在简略图中分别标清，不能两个端子都写 `+`。

### 急停状态

如果急停有两组独立 NC：

```text
S1A：切断 12V 水泵电源
S1B：连接 PB12 状态检测
```

如果只有一组 NC：

```text
第一版优先用于切断 12V
暂时不把同一触点同时接入 PB12
```

## 5. 固件最低行为

第一版固件只需实现：

```text
上电 PB5 默认关闭
PING → PONG
STATUS → ESTOP/PUMP
STOP → 关闭 PB5
非法命令 → ERR
```

接线和通信通过后再实现：

```text
PUMP action_id duration_ms
→ ACK
→ 定时关闭 PB5
→ DONE
```

协议细节见 [STM32 最小串口协议 v0.1](STM32最小串口协议_v0.1.md)。
