## 原架构的十个最大问题

1. 直接的规划到执行器路径绕过了独立的安全治理。
2. `main.py` 在没有已验证安全边界的情况下拥有自动启动组合路径。
3. 关键的通信、规划、标定和重建函数是 `pass` 桩。
4. 图像/Frame 和 Detection 类型不等同于任务级 StateEstimate。
5. 不存在结构化的 ActionRequest 或 SafetyDecision。
6. 命令意图没有实际值的 ExecutionReceipt 契约。
7. README 中的 “Return detection” 不是已定义的验证指标或 stop/retry/human 状态。
8. 基线中不存在可追溯的 State–Action–Outcome episode 模型。
9. 在单视图基线获得证据之前就突出了高级的双视图/3D/YOLO 模块。
10. 没有原始数据、标定报告、实验流程、结果或失败记录支撑声明。
