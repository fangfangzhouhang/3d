# MicroCleaningVision 文档总导航

## 1. 六个文件夹（不必全读）

```text
说明文档/
├── README.md                 # 你正在看的导航
├── 成员A/                   # 数据、U500、标注（命令字典）
├── 成员B/                   # 视觉识别（命令字典）
├── 成员C/                   # 路径和串口（命令字典）
├── 硬件组/                  # 接线、协议、联调

└── 未来计划/                # 长期证据关卡，做实验/模型时再读
```
