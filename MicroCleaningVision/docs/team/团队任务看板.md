# 团队任务看板：视觉软件闭环

每张卡只对应一个负责人和一组文件。共享接口有变化时另开接口提案，不混进功能 PR。

## A-01：图像质量与回放入口

| 字段 | 内容 |
|---|---|
| 负责人/分支 | A / `feat/a-imaging-quality-v0` |
| 文件 | `image_quality.py`、`replay_camera.py`、`test_member_a_imaging.py` |
| 输入 | PLA 测试片图片、采集条件和前/后阶段 |
| 动作 | 读图；计算清晰度、亮度/过曝指标；生成 Observation；处理文件缺失 |
| 输出 | 30～50 张清单、质量分数、质量标记、失败样本 |
| 学习 | OpenCV/NumPy、HSV、拉普拉斯方差、直方图、元数据 |
| AI 帮助 | 生成指标代码和测试；攻击跨倍率、反光和纹理阈值 |
| 验收 | 三次运行一致；坏图可解释地拒绝；不修改共享契约 |
| 预计 | 6～10 小时；依赖固定采集或现有图像 |
| 失败后 | 先记录失败条件，不为通过测试随意降低阈值 |

## B-01：HSV 污染测量

| 字段 | 内容 |
|---|---|
| 负责人/分支 | B / `feat/b-hsv-measurement-v0` |
| 文件 | `contamination.py`、`estimator.py`、`test_member_b_measurement.py` |
| 输入 | A 输出的合格 Observation 和图像 |
| 动作 | HSV 分割、形态学清理、轮廓筛选、面积/质心/置信度计算 |
| 输出 | ContaminationMeasurement 和 StateEstimate |
| 学习 | HSV、mask、开闭运算、连通域、假阳性/假阴性 |
| AI 帮助 | 生成候选参数与测试；不得让 AI 从一张图定义通用阈值 |
| 验收 | 空目标、多目标、反光、背景纹理均有测试或失败记录 |
| 预计 | 8～12 小时；依赖 A-01 的代表图 |
| 失败后 | 若固定条件仍不稳定，先统计原因，再提出模型 A/B |

## B-02：前后图配准与复检

| 字段 | 内容 |
|---|---|
| 负责人/分支 | B / `feat/b-pre-post-verification-v0` |
| 文件 | `area_change.py`、`test_member_b_measurement.py` |
| 输入 | 同一样本的合格前后图与污染测量 |
| 动作 | 检查可比性、对齐图像、计算残留面积和去除率 |
| 输出 | VerificationResult 和不可比原因 |
| 学习 | 配准、ROI、误差传播、阈值与不确定度 |
| 验收 | 错位、后图缺失、质量差时转 HUMAN；不假报成功 |
| 预计 | 8～12 小时；依赖 A-01、B-01 |

## C-01：回放编排与 FakeSerial

| 字段 | 内容 |
|---|---|
| 负责人/分支 | C / `feat/c-replay-loop-v0` |
| 文件 | `fixed_rule.py`、`governor.py`、`fake_serial.py`、`replay_mcl.py`、`test_member_c_workflow.py` |
| 输入 | B 输出的 StateEstimate 和前后 Observation |
| 动作 | 提出动作、独立审批、模拟 ACK/超时、生成回执、调用复检 |
| 输出 | 软件回放 Episode；未来 STM32 接口合同 |
| 学习 | 状态机、ACK、超时、幂等、令牌绑定、接口抽象 |
| AI 帮助 | 生成对抗性失败测试；检查审批重放和参数篡改 |
| 验收 | 不打开 COM；DENY/HUMAN 不执行；超时无成功回执 |
| 预计 | 8～12 小时；可先用结构化假数据并行开始 |

## 每周集成

A 给 5 组图 → B 生成状态和复检 → C 运行 Episode → 三人共同复盘。集成发现的问题回到对应所有者，不跨模块代改。
