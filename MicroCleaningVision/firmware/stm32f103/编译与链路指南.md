# STM32F103 实验固件：编译与链路指南

> 本文说明 `f103-stage1/` 按 A/B 职责重结构后，要达到 **编译成功** 和 **实机链路跑通** 各自需要的条件。
> A = 底层驱动与运动控制负责人；B = 系统控制与通信负责人。
> 允许少量共同文件（common/），其余两侧零交集。

## 1. 目录结构（重结构后，编译友好版）

```text
firmware/stm32f103/f103-stage1/
├─ driver_a/                  ← STM32-A 独占（底层驱动与运动控制）
│  ├─ main.h                 引脚宏（PB0 泵/PB2 急停/PB3 ARM/PA2-3 串口）+ STM32F10X_MD 开关
│  ├─ stm32f10x_conf.h       StdPeriph 库裁剪配置
│  ├─ stm32f10x_it.c/.h      中断向量（SysTick / USART2）
│  ├─ stm32f103_hal.c/.h     GPIO/UART/SysTick 底层驱动
│  └─ uart_rx_guard.c/.h     中断↔主循环 RX 环形缓冲
├─ system_b/                  ← STM32-B 独占（系统控制与通信）
│  ├─ control_core.c/.h      6 状态系统状态机
│  ├─ mcv1_protocol.c/.h     MCV1 协议解析 + action_id 去重
│  ├─ command_parser.c/.h    旧版裸命令解析
│  ├─ protocol.c/.h          旧版响应格式化
│  └─ line_receiver.c/.h     \r\n 行切割
├─ common/                    ← 共同维护（仅 2 个文件）
│  ├─ main.c                 不拆分：A 管 4 个初始化函数，B 管 main() 主循环
│  └─ fw_types.h             命令/输出数据合同（改动需两人评审）
├─ tests/                     ← 共享：8 个主机测试原位不动，各自新增测试文件即可
├─ scripts/run-host-tests.ps1
└─ README.md
```

要点：
- 两侧全部扁平，**无 include/src 子目录**，每侧一条 IncludePath 即可；
- 所有 `.c` 内容**逐字节不变**，只挪位置；
- 将来 X/Y 电机（STEP/DIR/EN、Timer 脉冲、限位、回零）全部新增在 `driver_a/`。

## 3. 实机链路跑通的条件

### 3.1 硬件接线（方案3：日常只留 USB-TTL，ST-Link 仅烧录时插）

| 连接 | 接线 | 说明 |
|---|---|---|
| USB-TTL ↔ STM32 | 模块 TXD → **PA3**，模块 RXD → **PA2**，GND 共地 | 接反则 0 字节通信 |
| 供电 | USB-TTL 的 **3V3 → STM32 3.3V 脚** | 若继电器吸合时欠压重启，换独立电源模块 |
| 继电器 | IN1 → **PB0**，5V 电源独立 | 低电平触发；PB0 高=释放 |
| 急停临时解除 | **PB2 → GND** | 正式方案应换 10k 下拉+按钮接 3.3V |
| 12V 泵路 | 12V 电源 → 继电器 → 泵 | 大电流不走杜邦线；人手保持能立刻拔 12V |

烧录时才临时插 ST-Link 四线（SWDIO/SWCLK/3.3V/GND），烧完拔掉；插 ST-Link 前先断 12V。

### 3.2 串口

- 设备管理器**肉眼确认** COM 号（禁止自动扫口）；
- 参数固定：**115200 8N1**，协议前缀 `MCV1`，一行最大 128 字节。

### 3.3 安全链（缺一不可，项目硬约束）

1. Safety Governor 人工关卡（HUMAN）；
2. `--confirm-pump`（人工确认）；
3. `--arm-pump`（显式武装）；
4. 有人在场，手能立刻拔 12V；
5. 单次泵时长 PC 侧硬上限 **300ms**（`fixed_rule.py`），固件接受 100–2000ms；
6. 未收到 `PONG` 且 `ESTOP≠0` 之前，不接 12V、不发 PUMP。

### 3.4 验证命令（顺序执行，全过才算链路通）

```powershell

.\.venv\Scripts\python.exe scripts\probe_stm32_link.py --port COM3 --command ping

```

### 3.5 验收标准

| 阶段 | 标准 |
|---|---|
| 编译 | Keil Rebuild 0 Error；主机测试 7/7 PASS；布局回归 PASS |
| 通信 | `PING → MCV1|PONG`；`STATUS → ESTOP=0|PUMP=0` |
| 空载（不接 12V） | PUMP 后继电器"咔哒"一声即释放，回执 `DONE` |
| 实喷（接 12V，人在场） | 300ms 单次喷射、`success` 回执、可重复 |
| 协议一致性 | 响应文本与 `STM32最小串口协议_v0.1.md` 逐字节一致（ACK≠DONE、action_id 去重、ESTOP 拒绝并锁存） |

## 4. 红线（任何时候不允许）

- 不得删除或绕过 `--confirm-pump` / `--arm-pump` 安全链；
- 不得改动低电平有效继电器极性（PB0 高=释放是安全态）；
- 不得让自然语言/模型/LLM 直接成为硬件命令；
- A、B 不得修改对方独占文件；`common/` 变更需两人评审。
