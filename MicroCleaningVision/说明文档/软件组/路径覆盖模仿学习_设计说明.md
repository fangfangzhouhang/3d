# 路径/覆盖模仿学习

核对日期：2026-10-20。这是离线软件研究，证据停在合成几何。它不修改串口、固件、安全关卡或工作台执行链。

## 1. 在解决什么

现有覆盖规划已经能在假定圆足迹下比较三种做法：连通域中心、扫描驻点、贪心最大增益（`plan_coverage`）。贪心往往用更少的点盖住目标，但访问连线不一定更短。真实喷点数据集还没有。

本轮先把「从完整污渍 Mask 预测一组喷点」做成可训练的软件管线：用现有贪心规划器当教师，合成 Mask 当题目。网络只预测热图。点是否允许、覆盖怎么算、和旧策略怎么比，都调用 `microcleaning/control_system/planning/` 里已有的核、可行域、指标和分析，不另写一套几何。

输出对象是 `learned-coverage-proposal-v1`。`executable`、`feeds_action_request`、`send_to_controller` 固定为 false。它不是 `ActionRequest`，也不能绕过 Safety Governor、人工确认或武装参数。

## 2. 训练思路

1. 生成或读入一张二值 Mask（合成，或将来的真实/人工 Mask）。
2. 用固定的假定圆形足迹调用 `plan_coverage`。默认直径 7 px、候选步长 4 px、最多 4 个驻点、名义覆盖目标 0.90。直径来源是 assumed，不是湿痕测量。
3. 把教师驻点画成高斯热图，作为模仿标签。标签含义是「贪心规划器会把喷点放在哪」，不是人工喷点，也不是清洁效果。
4. 一个小的全卷积网络（3 层 3×3 卷积加 1×1 输出）读入 Mask，输出同尺寸 logits。训练损失是热图像素的均方误差。
5. 解码时只在 `prepare_coverage_domain` 给出的可行驻点上取峰，距离过近的峰会抑制。然后从配置的起点做最近邻排序。最近邻只决定访问顺序，不是固件的斜线插补。
6. `evaluate_coverage` 计算几何覆盖率、点数和直线路程。`analyze_coverage` 在同一足迹、步长、预算和起点下给出中心点、扫描驻点和贪心三条对照。

默认命令就是微型 CPU 配置：32×32、训练 4 张、验证 2 张、2 个 epoch、通道数 8。它用来证明管线能跑完，不是规划比赛。

## 3. 合成数据

四种几何，随机种子可复现：

| 种类 | 形状 |
|---|---|
| `blob` | 一到两块椭圆团 |
| `split` | 多块分开的小圆 |
| `scratch` | 细长折线再膨胀 |
| `particles` | 许多半径 1–2 px 的颗粒 |

Mask 是 `uint8` 的 0/1，坐标 `image_px`，原点在左上，x 为列、y 为行。空图会补一个小圆，避免教师收到无目标。可用 `save_mask_archive` 存成 `plan-imitation-masks-v1` 的 npz（`masks`、`kinds`、`seed`）。

这些图不是 U500 画面，不能写入数据集清单冒充采集。

## 4. 真实数据到来时要什么

训练脚本可以改读目录：`--mask-dir <png目录>`。每张灰度 PNG 非零像素视为前景，文件名主干当作 `target_id`。此时 `mask_kind` 记为 `reference_annotation`，教师仍然是贪心规划器，除非以后另交人工喷点。

期望的单张记录：

```text
mask.png                         与规划输入同一尺寸的二值图，0 背景，非零前景
mask_kind                        segmented_stain 或 reference_annotation
coordinate_frame                 image_px
shape_hw                         [高, 宽]
source_ref                       批次、相机、算法或标注者
frame_id / image_sha256          能对回原图；本网络不读 RGB
footprint                        显式直径或足迹核、单位、assumed/measured
pixel_scale                      只有核用毫米时才需要；缺尺度不得假装像素直径
stations_xy                      可选。有人工喷点以前，不要把贪心输出改写成人工真值
```

划分按样品或拍摄批次，不要把同一段视频的相邻帧拆到训练和验证两边。人工框选区域继续保留 `manual_region` 语义，不要混进污渍面积。真实 Mask 未到之前，合成结果不能升级成现场证据。

## 5. 怎么跑

基础环境不要安装本依赖。YOLO / ultralytics 仍然不要装。

```powershell
cd D:\大创\3d\MicroCleaningVision
.\.venv\Scripts\python.exe -m pip install -r requirements\perception-opencv.txt
.\.venv\Scripts\python.exe -m pip install -r requirements\learning-torch.txt --index-url https://download.pytorch.org/whl/cpu
.\.venv\Scripts\python.exe -m microcleaning.data_learning.plan_imitation.train --tiny --output-dir output\plan_imitation\tiny
.\.venv\Scripts\python.exe -m microcleaning.data_learning.plan_imitation.evaluate --checkpoint output\plan_imitation\tiny\checkpoint.pt --samples 4 --output output\plan_imitation\tiny\eval.json
```

没有 torch 时训练和评估退出码为 2。几何单测在缺少 torch 时跳过网络用例，合成 Mask、教师和解码仍可测。`train_entry --backend yolo` 继续拒绝。`--backend torch` 或 `semantic-seg` 也返回 2，并指向上面的路径模仿命令；污渍分割网络没有接到识别入口。

## 6. 安全边界

- 解码只用可行域里的点。足迹超出图像的位置不会被挪成合法喷点。
- 提案、检查点旁的 `config.json`、评估 JSON 都写明三个硬件标志为 false。
- 本包不导入串口、编排、安全模块或固件。
- 将来若真要移动或喷水，必须由人把点列改写成现有运动申请，并走原来的 Safety Governor、确认和武装参数。本模块不提供这条转换。
- 几何覆盖率不是清除率。假定直径不是喷头尺寸。直线路程不是台面轨迹。

## 7. 强化学习只是后续笔记

模仿学习稳定、而且贪心在路程或时间上的失败已经被记录之后，才值得讨论强化学习（用覆盖、点数和路程作奖励的策略）。那一步需要单独的失败记录、对照和文件方案。当前没有实现，也不能把奖励接到泵或电机。

## 8. 下一步

1. 用更多合成形状确认解码在教师热图上能回到贪心点（这一步已有单测）。
2. 等 A/B 提供同尺寸真实 Mask 后，用 `--mask-dir` 只做离线对照，仍不执行。
3. 只有留出几何指标相对贪心有稳定差异，才考虑加宽网络或改损失。不要把微型 CPU 冒烟写成规划胜利。
4. 真实多驻点执行仍要独立安全方案和当次人工授权。
