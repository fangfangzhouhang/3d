更新：2026-10-05，main `341224f` + `feat/single-entry-cleaning-v1` worktree 未提交改动。原先“一条命令缺入口、会话和后图编排”的软件缺口已在本轮实现；实物闭环仍未验收。当前命令及偏移模板见 [现场可测入口](../硬件组/现场可测入口.md)，完整证据见 [EXPERIMENTS](../项目记忆/EXPERIMENTS.md)。

## 1. 原计划中已修复的地方

| 原问题 | 当前改动 | 软件证据与边界 |
|---|---|---|
| analyze/移动/喷水分开，无单进程闭环 | 新 `demo.closed_loop_station` 调用 CameraPreview、CleaningLoop、HardwareExecutor | 默认 Mock 连续三块成功；旧入口兼容保留。未喷水的去程回程已在 Cursor 终端走过一轮。分步喷水和复检还没实物运行 |
| 混合会话只存在于测试 | 同一 F103SerialSession 持续占用一个指定 COM，旧 STEP 与 MCV1 解析器各自负责 | FakeSerial 多轮只开一条连接；没有新增线上命令 |
| 居中后默认直接喷、泵审批在移动后才失败 | 本轮整套几何先展示/YES；移动前检查泵许可；移动后再次检查泵及回程令牌 | 拒绝/未武装/计数不足/令牌过期不喷；旧 direct-serial 脚本仍是独立债务 |
| READXY 只看忙闲，少发脉冲也可能被算完成 | 非零轴要求已发计数等于本段申请，保留完整 Stage2TransmitResult | 计数不足退出 ERROR、PUMP 为 0；零轴允许保留上一段计数；不是位置反馈 |
| 只反转针头偏移，回不到原视野 | RETURN 反转目标位移与偏移之和，去程前预留回程预算 | 三块后账本回原观察位；未知/中途运动失败不造成功 |
| 按整图面积复检、裁剪后坐标改变 | 同尺寸单目标 Mask 交原规划器，已有匹配规则只核对所选目标 | 其它污渍变化不算该目标成功；模糊匹配 HUMAN |
| T1 变号就当新污渍，重试可无限重置 | 独立 S0001 稳定账本、每帧 T 编号、有限新帧重试 | 合并/分裂/多重匹配或已完成目标可疑重现交人 |
| 前后自动加载不同策略、旧帧冒充后图 | 同进程相机、新帧身份/时间、启动时锁定分割策略和哈希 | 质量失败、设置改变、非同视野、陈旧后图不能自动通过 |
| STOP 先读到被中止动作 ERR 就遗留回复 | 有界读完 ERR→ACK STOP→DONE STOP 并留原文；会话失败关闭/锁定 | 失败矩阵通过；未测真实电气停止 |

## 2. 严重阻塞：先补实测坐标和装配条件

H2 必须给电机方向、像素位移响应、载物台参考位置及显微镜中心到喷头中心的**有符号**载物台位移。新偏移接口已预留并执行一次；null 不能当零，实物必须绑定电机标定 SHA256、装配编号、来源和不确定性。

`q_exec=q_obs+d_target+d_offset`；回原观察位必须 `-(d_target+d_offset)`。样品移动、观察组件固定，像素移动方向与台面方向需要实测转换。旧 nozzle_px 或非零 nozzle_offset_mm 会被拒绝，不能重复补偿。

2026-10-08 起，主机不再另设单次步数上限。能否移动只看位置账本，人工零点两侧各 10000 步。没有限位开关。固件一条报文仍是最多 20000 步。

人工零点与账本不等于回零传感器或绝对定位。实物启动需人确认当前装配/上电仍与参考对应；READXY 满计数仍需独立位移和回程误差验收。

## 3. 高优先级：同次固件、短喷及前后图

H1 主交同一联合固件的构建/烧录身份及实际 PB0/PB2/PB3 条件，H2 复核；保留 PING/STATUS、STEP 回执、停止与短喷起止原文和测量。主机从 STATUS 读取联锁，不凭空写 True；STATUS 本身仍不证明现场接线或独立断电。

A 固定倍率/光照/夹具，保存一次动作前、回程后新抓的图及采集条件；B 检查同视野可比性和目标匹配，独立人工复核残留。当前实物可比性仍需人输入 YES，没有自动配准或自动损伤检测。0.80 去除率只是旧规则阈值，没有被此次 Mock 科学验收。

C 在配置齐全后只做 CENTER_POINT 的受限现场记录。程序参数存在不代表已获本轮动作许可。实物确认和显微镜在同一个窗口。第一次画面的编号顺序就是清洗顺序，有几块处理几块，后面新分出来的区域不新开清洗。复检对不上时，确认结束这一块后仍继续下一块。短喷默认 500 ms。武装喷水后，去程、针头重合、短喷、回原位、复检和下一块各自都要再确认。失败时查档案/停止，不重放旧令牌或旧动作。`station_20261008_203402_ed901155` 只喷了 S0001，S0002 没喷；编号顺序的修正还没有在 COM8 上再跑。

## 4. 中优先级与暂不扩展项

多污渍排序负责“下一块选谁”，原清洗规划负责“这块内部怎么走”；现在复用 nearest_neighbor/area_desc/weighted_score，未训练学习排序模型。V1 扫描 RASTER_SCAN 会 HUMAN，没有边移动边喷或新增剂量算法。

旧 center_object.py 与标定脚本仍直接发串口，统一授权、耗尽判失败和异常关泵应另列文件级改造，不能因为新入口有 YES 就写所有脚本都被保护。共享运动合同仍未升级；完整运动证据放侧文件，泵回执放 Episode，不把 MOVEXY 填成喷射请求。
