# MicroCleaningVision 五页工作台 v3 操作手册

更新：2026-10-10。使用前先区分三件事：流程走完、图像结果可信、实物洗净。它们分别有证据，不能互相代替。

## 1. 启动与页面顺序

```powershell
cd D:\大创\3d\MicroCleaningVision
.\.venv\Scripts\python.exe -m demo.closed_loop_station --mock --workbench --algorithm hsv --mock-scenario workbench-residual
```

这是合成演示，不连接相机或串口。普通 `--mock` 不加 `--workbench` 仍运行旧 CLI 有限轮数回归；工作台的人工复洗不受 `--max-cycles` / `--max-retries-per-target` 限制。

| 页面 | 操作 | 系统实际做什么 |
|---|---|---|
| 封面 | 填样品和操作员，开始检测 | 启动本任务帧源；历史入口只读旧任务 |
| 实时检测 | 检查画面，采集并识别 | 冻结首次原图，生成稳定 S 编号候选 |
| 目标审核 | 确认、排除、待复核、补框、撤销；确认并锁定；开始执行 | 仅锁定已确认且可定位子集；留白不创建目标；执行后不能改名单 |
| 清洗监控 | 查看原图/实时图、当前目标、中文阶段和授权卡 | 真实 MOVE 阶段自动进入；移动、喷水、回程仍分别授权 |
| 结果报告 | 按目标→清洗轮次→复检次数选择，比较放大图，导出/打印 | 最后目标有效复检并获认可才自动跳转；报告由用户选择生成 |

可前进/返回查看已发生信息，切页不发送硬件命令。监控页内容可滚动，中文日志可收起。顶部动画反映当前阶段与已处理/锁定目标数；无限复洗期间不能承诺固定剩余时间，也不能将一次按钮点击当作完成一个目标。

## 2. 每次复检后的四种选择

清洗→回原观察位→采后图→验算固定区域→人工决定。四个选项的作用如下。

| 选择 | 下一步 | 是否自动批准物理动作 |
|---|---|---|
| 再洗一次 | 保持同一 S 编号，重新采前图、验证位置、按当前残留重新规划，逐步获得新的授权 | 否 |
| 不复洗 / 下一个污渍 | 中间目标保存当前结论后开始下一个，不把残留改成洗净 | 否 |
| 仅重拍复检 | 增加同一次清洗的复检记录，不移动、不喷水 | 否 |
| 暂停并保存 | 停止本次执行并保留未完成状态，留在监控/档案 | 否；当前没有原任务一键断点续跑 |

没有业务复洗次数上限。每轮仍受单动作许可、串口完成检查、位置可信度、成像质量、超时和人工取消约束。不得重放前一轮 PUMP 或授权令牌。前景已消失且无法可靠定位时，禁止盲目复喷，使用重拍/人工判读。

最后一个目标只有两个出口可以完成：有效结果达到当前回放判据后被认可；或前后位置和图像可信、人工填写理由后明确确认通过。视野偏移、弱纹理、坏图或重复旧帧不能靠填写理由绕过。未满足条件时，保留复洗、重拍、暂停选项，不自动进入打印。

前面的污渍如果被选择“不复洗”但仍有残留，报告继续记 FAIL；最后目标认可并不擦掉此前结果。结果页的质量审计只追加结论，不会偷偷恢复已结束的硬件任务。

## 3. 怎样阅读清洗率与重合图

首次污渍所在矩形和原图坐标固定，已知邻近污渍从测量域排除。分割阈值、归一化峰值、模糊核和所选分支冻结；后图只更新这个区域。全图重扫描仅在周围变化等情况下作为二次确认，不能重新给当前目标编号或替代面积基线。

测量前先用污渍外的背景检查首次参考→本轮前图、本轮前图→后图。默认测得位移容差为 0.25 px；不平移/扭曲后图来制造对齐，超过容差、纹理不足、局部光照/清晰度异常等结果无效。这个数字是工程保护阈值，尚未被真实采集验证，不能证明物理位置数学意义上完全相同。

设前后同位置掩膜为 M前、M后：

- 本轮清洗率 = (前面积 − 后面积) / 前面积；当前轮前图是新采集图。
- 累计清洗率 = (首次面积 − 当前后面积) / 首次面积。
- IoU = 交集 / 并集；Dice = 2×交集 / (前面积+后面积)。重合度用于解释残留位置，不等于清洗率。
- 例：前 1000 px、后 250 px、交集 200 px，则本轮减少 75%，IoU 约 19.0%，Dice 32.0%。若后面积变大，清洗率可以为负，不截成零。

监控页并排展示同尺度的前污渍、后污渍、叠加图，并列出面积、IoU/Dice、位移及原因。绿色代表减少，黄色代表重合残留，红色代表新增前景。

按本轮用户要求，完全未检出可靠前景显示 **0% 且无效/未检出**，不会自动解释为 100% 洗净。存在视野偏移等问题时有效清洗率为空并提示原因。背景对应可信且后前景为空，可由人工结合放大图填写理由认可；原始零值和无效标志仍保留，报告注明人工依据。自动 0.80 只是现有回放阈值，不是经实物验收的洁净标准。

## 4. XY 与喷头示意图

位置卡显示已确认的累计指令位置、当前脉冲估计、预计终点、参考时间和可信状态。READXY 返回本段发出的脉冲和忙闲，不能测到丢步、手移或实际机械位置。

发 MOVEXY 前持久化 MOVING/PENDING，完整结束后才提交累计位置。中断、错误或带未完成记录重启变为 POSITION_UNCERTAIN；真实工作台新任务要求人工重新建立实物参考，不能简单沿用旧 JSON。UNHOMED/READY/MOVING/POSITION_UNCERTAIN 等状态不等于自动回零硬件。

实时图右下角的喷头图消费实际生效的有符号显微镜→喷头偏移、电机标定、来源/哈希及不确定度，并结合累计/当前脉冲绘制预计关系。缺标定、位置未知时不显示正常对齐。本图是标定约束下的预计位置，实物中心精度仍须现场测量，不能靠画一个十字获得精度。

当前用户已移除软边界拦截：不显示虚构的四向机械剩余行程，不恢复 ±10000 默认边界。一条 MOVEXY 每轴仍最多 20000 步。真实行程、原点开关、限位、编码器和自动回零尚未实现/验收。

## 5. 记录、报告与历史读取

原任务自动留档，结束时不自动导出或打印。结果页可选 HTML、中文 UTF-8 BOM CSV、两者，或打开可打印 HTML 后由用户选择打印机/另存 PDF。本版没有直接 PDF 生成依赖；未完成浏览器排版、物理打印/PDF 保存验收。

每个污渍的每次清洗和每次重拍复检分别保存：原前后图、固定区域 Mask/放大图/叠加图、面积/清洗率/累计率/IoU/Dice/配准依据、冻结分割参数、动作编号、中文 XY 规划、脉冲回执、请求喷洗时长、质量结果与人工选择/理由/时间。ACK/DONE 不能证明实际出水；实测出水时长未记录。

```text
station_*/
  run_config.json / task_manifest.json / review_log.jsonl
  roi_reference_Sxxxx.json / roi_reference_Sxxxx_mask.png
  cycle_NNN/
    pre.png / pre_mask.png / pre.json / geometry.json / execution.json
    recheck_XXX/
      post.png / post_mask.png / post.json / verification.json / decision.json
      roi/ 前后裁剪、叠加、合成对照、metadata及哈希
    cycle.json   # 全部复检；旧 post/verification 键镜像最后一次
  stage_events.jsonl / serial.json / progress.json / summary.json
  reports/report_版本/ index.html / task.csv / targets.csv / attempts.csv / assets/
```

`attempts.csv` 每次清洗的每次复检各占一行。读档按数字排序轮次、校验包括中间轮次的图片与 ROI 文件哈希；坏图、缺图、篡改和路径逃逸不能得到正常打印许可。历史任务允许只读查看和导出；自动跳页与打印许可读取 report_ready，不能用 SUCCESS 或最后一次质量值替代。

## 6. 正式入口与维护入口

实物入口默认使用工作台；须明确指定相机、COM、实测标定/有符号喷头偏移及武装参数，并重新建立人工参考，遵守每阶段授权。参数模板见[现场可测入口](../硬件组/现场可测入口.md)，不能将本次软件测试当作实物授权。

居中工具须 `--maintenance-mode --no-spray`，尺度标定和短命令运动须 `--maintenance-mode`。维护每次运动限制为每轴 1000 步、逐次 YES，发令前使正式位置账本失效；结束后重新建立正式参考。工作台与维护工具按 COM/位置文件加进程锁。短命令工具只接受单行白名单，旧偏移/喷水入口禁用；停止由原设备所有者收尾，不开第二个 COM 抢控制。
