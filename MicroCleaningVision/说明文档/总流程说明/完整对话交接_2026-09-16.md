## 8. 重要决策及其理由

| 决策 | 理由 |
|---|---|
| 主算法用 `local` 不用 HSV | HSV 在 `public_001` IoU=0.0739；污渍不保证是高饱和红 |
| 过关集必须是 U500 固定条件实拍 | 算法要认这台显微镜、这个工作距、这盏灯；网图分数无法接到这台泵 |
| 旧 13 张只当软件回归 | 来源 unknown；文件夹名 public ≠ 证据 |
| 开发/留出按名单冻结，且按批次切新数据 | 用测试图调参是自欺 |
| 训练入口只做 OpenCV 调参 | 用户要小改、要自动比 Mask 改参数；深度学习门槛未到 |
| 默认 review 一轮就停，不默认 `--apply` | 用户要自己看叠加图；自动写入会把噪声进步冻进全局 |
| `--apply` 条件：开发集 IoU 严格提升且留出未变差 | 防止过拟合写进 Demo |
| 代码内 v0.1 默认值不直接改，只写 JSON | 旧评价对得上；`--no-tuned-policy` 可回退 |
| 少于 3 张开发图不改参 | 用户后来自己问过拟合；一张变好换一张会崩 |
| 同学机喷水后不冻结本机代码 | 成功副本不在本地；乱覆盖会把安全闸和 Demo 搞乱 |
| 近场不买 XY / GPU | 没有行程数字、没有失败类型、没有显微镜数据集 |
| 路径先做像素预览可读 | 无标定、无湿斑直径、无喷头偏移时，毫米路径是假的 |
| 若做模型：语义分割，禁 YOLO | 任务是区域不是框；AGPL；作战总表禁止 |
| 向顾老师主推「数据 + 可评价识别 + 复检」 | 大创竞争力在可复盘闭环，不在模型名词；现在上模型纸上谈兵 |
| 数院同学做评价与切分 | 老师问的是岗位必要性，不是私人关系 |

`LocalContrastPolicy` 当前代码默认（v0.1，不要默默改这些数）：

```text
blur_kernel_px=0（按图自适应）
lightness_weight=0.55
color_weight=1.0
min_residual=8.0
min_component_area_px=20
max_aspect_ratio=6.0
max_area_ratio=0.20
morphology_kernel_px=3
```

建议一次只动：碎点 → `min_component_area_px`；铜线 → `max_aspect_ratio`；弱斑 → `min_residual`；整图涂白 → `max_area_ratio`。改完升版本号，例如 `local-contrast-v0.2`。

OpenCV 可停训（作战总表）：U500 labeled 留出 n≥10、跨 2 批次，连续 2 个版本 mean IoU≥0.50、灾难率≤10%、P/R≥0.50、整图涂白 0 张。达不到且有稳定失败类型，才允许谈分割模型。另需成像固定、≥50 原图、≥30 labeled、负样本约 10%。
