## 零、开发环境搭建（团队成员必做）

### 0.1 环境要求

| 项目 | 版本要求 | 说明 |
|------|----------|------|
| Python | 3.10+ | 推荐使用 3.12 版本 |
| CUDA | 12.0+ | 若使用GPU加速训练/推理 |
| Git | 最新版本 | 代码版本控制 |

### 0.2 操作步骤

#### 第一步：克隆仓库

```bash
git clone <仓库地址>
cd microcleaningvision
```

#### 第二步：创建虚拟环境

```bash
# 创建虚拟环境
python -m venv venv

# 激活虚拟环境（Windows PowerShell）
.\venv\Scripts\Activate.ps1

# 激活虚拟环境（Windows Command Prompt）
.\venv\Scripts\activate.bat

# 激活虚拟环境（macOS/Linux）
source venv/bin/activate
```

**注意**：每次打开新终端都需要重新激活虚拟环境。

#### 第三步：安装依赖

**3.1 升级pip并安装基础依赖**

```bash
# 升级pip（推荐）
pip install --upgrade pip

# 安装基础依赖（不含PyTorch）
pip install opencv-python==5.0.0.93 numpy==2.0.0 ultralytics==8.4.92 pyserial==3.5 matplotlib==3.11.0 loguru==0.7.3 PyYAML==6.0.3 pillow requests psutil
```

**3.2 安装PyTorch（关键步骤）**

根据你的环境选择以下命令之一：

**方案A：使用CUDA加速（推荐，需NVIDIA显卡）**

```bash
# CUDA 12.4版本（推荐）
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124

# 或使用国内镜像加速
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124 -i https://mirrors.aliyun.com/pypi/simple/
```

**方案B：仅使用CPU（无NVIDIA显卡）**

```bash

```

### 0.3 常见问题

**Q1：激活虚拟环境时报错 `无法加载文件 ...\Activate.ps1`**

**解决方案**：以管理员身份运行PowerShell，执行以下命令：

```powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
```

然后重新激活虚拟环境。

**Q2：安装opencv-python失败**

**解决方案**：

```bash
# 尝试指定版本
pip install opencv-python==5.0.0.93

# 或使用预编译包
pip install --no-cache-dir opencv-python
```

**Q3：运行项目时提示缺少模块**

**解决方案**：

```bash
# 确保已激活虚拟环境
pip install <缺失的模块名>

# 更新requirements.txt
pip freeze > requirements.txt
```

### 0.4 环境更新

当项目依赖发生变化时，按以下步骤更新环境：

1. **拉取最新代码**
   ```bash
   git pull origin main
   ```

2. **重新安装依赖**
   ```bash
   pip install -r requirements.txt --upgrade
   ```

3. **验证更新**
   ```bash
   python test_env.py
   ```

## 七、协作规则

### 7.1 代码提交规范
- 遵循Conventional Commits规范
- 每个提交只包含一个功能或修复
- 提交信息清晰描述修改内容

### 7.2 分支管理
- 每个功能创建独立分支：`feature/xxx-description`
- 开发完成后发起Pull Request到develop分支
- 至少一位成员审查通过后合并

### 7.3 接口约定
- 模块间通过 `utils/types.py` 中定义的数据类传递数据
- 禁止直接传递tuple、dict等松散类型
- 新数据类型必须在 `utils/types.py` 中定义

- 所有模块使用 `utils/logger.py` 记录日志
- 必须提供 `module` 和 `function` 参数
- 使用合适的日志级别

### 7.5 进度同步
- 每日站会同步进度（10分钟）
- 每周五进行代码审查和进度评估
- 遇到阻塞问题及时反馈
