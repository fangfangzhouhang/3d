## 3. 当前通过测试能证明什么

- 接口对象、模拟失败路由和Episode存储可回归；
- 回放相机能真正解码本地图片文件；
- 文件缺失或伪图片会被拒绝；
- 没有标定时状态估计不会产生毫米目标；
- 未准备好、越界、篡改或过期的模拟动作会被拒绝；
- FakeSerial能模拟成功和超时回执。

不能证明：

- USB显微镜采集稳定；
- 质量阈值适合真实显微图；
- HSV能识别PLA模拟污染；
- 前后图片可以真实配准；
- 目标点可转换成工作台坐标；
- STM32、泵、电机或喷头执行；
- 真实清洗有效或无损伤。

## 4. 当前最大瓶颈

当前已有13条来源待核实的metadata、13份候选Labelme JSON和13张自动转换的人工Mask，但仍没有团队采集的真实USB显微镜批次。只有`public_001`完成人工复核、metadata确认和定量评价。单图评价已经证明当前HSV会把横向背景结构误检为污染；下一瓶颈是逐份复核现有Mask，并按开发图/留出图验证改进，而不是继续增加空框架。

最短下一步不是新增模型，而是：

```text
A逐份复核现有标注，冻结3张开发图和至少2张留出图
→ B保留HSV v0.1并提出形状过滤v0.2
→ A在留出图片上独立比较
→ 证据支持时才替换Demo默认算法
```

## 5. 旧仓库事实

`legacy/`保存早期相机、检测、规划、通信、模型和3D代码。历史审计发现大量核心函数为桩或未验证，并存在直接规划到控制器、接口类型不匹配、缺数据/标定/固件等问题。当前主线不导入它们。

旧详细文档已从当前工作目录清除，避免旧分工、旧路径和固定 YOLO→双目→3D 路线误导新人；需要追溯时从 Git 历史读取。
