# 团队入门指南：共同搭一台会自我复查的实验室助手

## 你第一周真正要学会什么

不是背完一串新名词，而是能把下面这句话讲清楚：

> 我们不是在做“识别污渍后自动喷水”，而是在训练一套能看见、谨慎行动、核对结果并留下证据的微观表面处理能力。

如果你能解释一次动作为什么被拒绝、设备回执为什么重要、动作后为什么还要拍图复查，你已经理解了系统的骨架。CNN、YOLO、3D 都是以后可能换上的“器官”，不是现在要先盖起来的“空楼层”。

## 每个人都必须解释的一个心智模型

把平台想象成一位谨慎的实验室助手。英文名会出现在代码里，右边的中文含义才是团队讨论时应使用的语言：

```text
Observation = 它的眼睛这一次测到了什么
State = 它认为当前哪些信息足够可靠、可以据此行动
ActionRequest = 一份建议执行的小实验申请
SafetyDecision = 安全权限，不是“谁更聪明”的比赛
ExecutionReceipt = 现实中的设备究竟做了什么
Verification = 现实是否按预期、且没有损伤地改变
Episode/Failure = 下一次实验能从中学到什么
```

图像不是 State：它缺少标定、不确定性、设备状态和先前动作历史。命令不是回执：泵或载物台可能并没有完成软件所请求的动作。一个好的检测分数并不等于清洁结果：只有合格的观测后检查才能确立结果。

## 共享概念与最小实操检查

| 概念 | 在本项目中的含义 | 现在需要学到哪一层 | 最小任务与验收标准 |
|---|---|---|---|
| 坐标系 | `work_mm`、标定版本、不确定性 | 全员：理解方向/单位/误差；A+C 先实现 | 每位成员映射一个标定目标点，并解释为何过期的映射会导致喷涂未命中。 |
| 安全治理器 | `ActionRequest -> ALLOW/DENY/HUMAN` | 全员：解释权限分离；B 实现 | 提交一个无效动作；测试必须显示没有控制器调用，并给出明确原因。 |
| 回执 | 实际位姿/剂量/误差，而非预期命令 | 全员：解读；B+C 测量 | 比较请求的空运行运动与实际运动，并识别任何不一致。 |
| 验证 | 同条件前/后 + 质量/配准 | 全员：理解；A 负责度量 | 创建一条配对图像记录，并附有文档化的配准检查。 |
| Episode/failure | 可追溯的 State–Action–Outcome | 全员：读/写；B 存储模式 | 每人创建一条失败记录，包含首发症状和恢复方式，而不仅仅是“失败”。 |
| OpenCV | P1 阈值基线 | A：实现/验证；B/C：理解输入/输出/误差 | A 运行固定样本检测基线；B/C 能说明低置信度对 Safety 意味着什么。 |
| CNN/YOLO | 可能的 P2 感知升级 | A：训练/评估基础；B/C：仅输入输出 | 不是 P1 交付物。仅在出现可重复的基线失败和 A/B 计划之后才启动。 |
| Transformer | 后期可能的上下文模型 | 全员：目前仅停留在概念层面 | 默认不属于 P1/P2。仅在有实测的长上下文/多模态失败时才正当化。 |
| PINN | 可能的物理预测方法 | 全员：目前仅停留在概念层面 | 当前不涉及。仅在具备可辨识方程、有限数据且有 A/B 增益时才考虑。 |
| 流程图 / Agent / 技能卡 / 共享记忆 | 流程图负责路由；Agent 处理一个有限问题；技能卡是可重复流程；共享记忆是全团队认可的事实 | 全员：概念 + 能追溯一次失败 | 通过 `docs/05_研发协作流程图.md` 追溯一次失败；解释为何 Agent 不能控制硬件。 |

## 责任与共享系统问责

| 所有者 | 拥有结果 | 必须理解上游/下游 |
|---|---|---|
| A — 感知与测量 | 成像协议、标定、检测质量、验证 | 其输出只是提议输入；它必须提供不确定性和动作后证据。 |
| B — 控制、安全与集成 | Action 模式、治理器、确定性协议、回执、集成/失败测试 | 它必须拒绝不可信的感知，并为 A 的验证提供事实性输出。 |
| C — 机构、工艺与实验载体 | 工作空间、喷嘴/泵/夹具、重复性、介质/废液、机械安全 | 它必须将物理限制转化为 B 的策略，并支持 A 的标定/验证。 |

## 关键纪律

不要说“我的模块做完了”。要说：“在条件 Y 下，完整闭环现在能做 X，证据是 Z；它在情形 W 下仍然失败。”这种表述方式能避免三个局部演示变成一个看不见的集成失败。

## 每个人的第一个“全局练习”

三人围着一条模拟 Episode 一起读十分钟：A 说清图像质量为什么不够就不能定位；B 说清为什么 `DENY` 时控制器不能收到任何字节；C 说清工作空间、喷射剂量与损伤边界如何进入安全规则。谁讲不清，不是个人能力问题，而是系统里还缺共同语言——立刻写到失败记录或任务板上。
