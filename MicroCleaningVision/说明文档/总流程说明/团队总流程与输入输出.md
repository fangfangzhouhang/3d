# 当前总流程

一条已经接通的链路是：抓一帧，算出污渍路径，变成 `MOVEXY`，STM32 驱动两台步进电机。当前联合固件已包含限时喷水和联锁，但正式电脑运动入口仍不发泵，移动与喷水的主机编排尚未统一。发送步进时尺度来自电机位移标定 JSON，但毫米仍依赖 5 mm/圈 的铭牌假设；只看路径时默认仍是 0.01 mm/像素占位。电机转了不等于已经标定、对准或清洗。

```text
摄像头或图片
→ 质量检查
→ 污染掩膜、面积、中心
→ 像素路径
→ 假设毫米，再按 320 步/mm
→ 每段一条 MOVEXY（X、Y 各自最多 1600 步）
→ HELLO 得到 STEP_OK v0.3
→ 两轴同时走，READXY 到都停稳
```

协议和接线只看 [串口协议与参数](../硬件组/串口协议与参数.md)。

只看路径、不打开串口：

```text
.\.venv\Scripts\python.exe -m demo.demo_pipeline --from-camera --mode analyze --stage2-xy --camera-index 0
```

真要转电机，按顺序做三步：

```text
# 1. 人把台面对到参考位置（工具在画面中心），记零点。每次上电、每次发送失败后都要重做
.\.venv\Scripts\python.exe -m demo.demo_pipeline --stage2-set-zero

# 2. 用电机位移标定 JSON（scripts/calibrate_motor_mm_per_px.py 的输出）规划并申请运动
# 3. 程序打印步数和位置，人在电机旁输入 YES 才发送
.\.venv\Scripts\python.exe -m demo.demo_pipeline --from-camera --mode stage2-move --stage2-calibration output\calibration\cal_<时间>\mm_per_px.json --arm-stage2-xy --serial-port COMx --camera-index 0
```

运动关卡（`microcleaning/control_system/safety/motion_gate.py`）在以下情况直接拒发：没有标定或标定带警告、位置账本未知、每轴累计超过 1600 步（代码常量，命令行只能调小）、途中任一点超出零点 ±3200 步软限位。软限位只是计数，不是回零或限位开关。路径从画面中心出发，不再从图像左上角出发。每次运行写 `stage2_intent.json`（打开串口前）和 `stage2_receipt.json`（发送后，无论成败）；发送失败时位置账本标记未知，需重新对位归零。`--live` 只看画面，不能同时发步进。

| 环节 | 代码 | 交给下一环的东西 |
|---|---|---|
| 成像 | `demo/demo_pipeline.py`，相机或图片 | 一帧像素 |
| 识别 | `microcleaning/vision/` | 掩膜、面积、中心 |
| 路径 | `microcleaning/control_system/planning/` | 像素路径和 `MOVEXY` 文本 |
| 串口 | `stage2_protocol.py`、`stage2_link.py` | `HELLO` / `MOVEXY` / `READXY` |
| 执行 | `firmware/common/main.c` → `firmware/motion/` | 两台 DM542 的脉冲 |

A 负责数据和标注，B 负责识别，C 负责路径和串口文本，硬件组负责 F103 固件和接线。人工标注只用来评价，不送进识别。

## 硬件组整理后的交接边界（2026-10-05）

H1 改 firmware/pump，H2 改 firmware/motion，共同入口和 Keil 在 firmware/common。旧 Stage 1 在 common/compat/stage1 留作回归，不要求移动与喷水轮流烧录。

固件主循环已接安全状态机：PB2 急停、定时关泵、STOP 关闭两轴和泵。TO_NEEDLE/TO_SCOPE 已走同一 XY 驱动，24 mm/7680 步仍是名义偏移；正式 Stage2SerialLink 不发送这些命令，不允许绕过 1600 步预算直接试跑。

scripts/center_object.py/标定脚本未在本轮修改，仍需 C 另行统一授权、失败判断、异常补关和偏移来源。固件接通不等于所有 Python 入口接通，也不等于真实前后图闭环完成。首次烧录前还须核对 PB2 常闭接地条件；本轮未操作硬件。
