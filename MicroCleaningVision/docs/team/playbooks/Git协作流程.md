# Git 协作技能

## 使用时机

在开始范围明确的任务、变更契约或移交已测试的变更时。

## 流程

1. 确认仓库根目录为 `D:\大创\3d`，检查 `git status`，不要覆盖无关的变更。
2. 在创建窄分支前，读取 `project_state.yaml` 和相关契约。
3. 使用问题/能力/证据信息进行小提交。
4. 运行最窄的相关测试。硬件测试从不在默认 CI 中运行，并需要人工关卡。
5. 使用 `docs/team/团队任务看板.md` 中的任务卡；PR 必须包含风险和回滚。

## 验收标准

审查者无需阅读聊天记录就能识别问题、契约影响、证据等级、命令/测试、产生的产物和回滚。
