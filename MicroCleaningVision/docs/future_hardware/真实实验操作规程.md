# 真实实验操作规程 v0：做一次可解释的闭环，而不是拍一次演示视频

## 使用这份规程前，请先停十秒

这是一份**实验前的共同检查表**，不是“照着按下运行键就可以”的授权书。真实动作的基本原则很朴素：

> 不清楚，就不动作；没有回执，就当作没确认；没有复查，就不宣称成功。

第一次实验的目标不是把污渍洗得最干净，而是得到一条任何成员以后都能复看、复做、解释的完整记录。

## 范围

这是**协议草案**，并非操作硬件的授权。项目负责人、安全/实验操作员以及全部三位负责人必须填写括号内的字段，并在首次真实动作之前批准物理流程。

| 字段 | 必须在 P1 之前冻结 |
|---|---|
| 样品 | `[material, geometry, sample ID rule]` |
| 污染 | `[one manufactured contamination recipe and amount]` |
| 成像 | `[top camera, magnification, exposure, light, focus rule]` |
| 清洗介质 | `[medium, compatibility, disposal]` |
| 物理原语 | `[one nozzle, safe duration/pressure/range measured by C]` |
| 坐标系 | `work_mm`、原点、轴、回零参考、单位 |
| 成功/停止判据 | `[pre-registered residual/damage criteria]` |
| 操作员 | `[name/role]` |

## 一次实验回合怎么走

把一次 Episode 想成“给样品做一次完整病历”：先留动作前证据，才允许提出治疗方案；治疗时记录实际剂量；治疗后必须复查。下面十步缺任何一步，都是未完成的实验记录。

1. 分配一个不复用的 `task_id`；记录操作员、样品、协议、软件/硬件/标定版本。
2. 运行设备清单：急停(E-stop)、守卫/联锁、限位/回零、液体/废液、通信、相机以及标定有效性。任何未知项均为 `DENY`。
3. 采集并保留不可变的动作前图像。拒绝低对焦/照度或图像配准检查失败的图像。
4. 生成 `Observation` 和 `StateEstimate`；没有在有效期内的 `work_mm` 标定和有界不确定性，就无法执行动作。
5. 记录一个候选的 `ActionRequest`。规则/模型可以提议，但不能操作硬件。
6. 运行独立的安全治理器检查。`DENY` 表示无运动/流体。`HUMAN` 表示操作员审查，而非伪装的重试。
7. 仅当前有效的 `ALLOW` 令牌允许确定性控制器执行。将控制器的实际值和错误状态保留为 `ExecutionReceipt`。
8. 返回定义的观测位姿，采集动作后图像，并在与动作前证据比对之前执行配准/质量检查。
9. 记录 `VerificationResult`：`STOP`、`RETRY` 或 `HUMAN`。在另行批准的策略存在之前，禁用自动重试。
10. 持久化 Episode 和任何 FailureRecord。绝不要因为一次失败的试验不方便就将其删除。

## 从零到真实动作的安全台阶

不要跳级。阶段 3 的“空运行”成功，只说明控制和回执的链路值得继续查；它不说明清洗有效。阶段 4 之前不要对真实样品做不可逆操作。

| 阶段 | 允许的物理动作 | 证据关卡 |
|---|---|---|
| 0 | 无 | 任务卡和风险边界已批准 |
| 1 | 仅相机 | 十张可追溯的固定条件图像；已定义质量规则 |
| 2 | 仅标定靶标 | 已记录 `work_mm` 配准误差/不确定性和过期规则 |
| 3 | 控制器空运行/无液体 | 急停(E-stop)、限位、回执、超时和安全停止证据 |
| 4 | 在批准的虚拟样品上执行固定有界动作 | 动作前/后证据和损伤观测 |
| 5 | 二十个受控基线回合 | E3 评估，而非假定成功 |

## 实验完整性：让未来的你也能相信今天的你

- 保留原始的动作前/后图像，并通过 ID 和哈希链接所有派生的掩码/指标。
- 在分析中包含失败、被拒绝和人工干预的试验。
- 在看到测试集之后不得调整成功阈值，除非将变更记录为新的协议版本。
- 如果一张“干净”的动作后图像的对焦、照度、配准或样品身份无法确立，则该图像无效。
- 对于任何未来的高级模块，应预先登记其失败目标、A/B 对比、KPI、成本和移除准则。
