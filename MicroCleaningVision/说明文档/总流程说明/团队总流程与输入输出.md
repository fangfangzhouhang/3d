# 当前总流程

一条已经接通的链路是：抓一帧，算出污渍路径，变成 `MOVEXY`，STM32 驱动两台步进电机。喷水是另一份固件，不在这一次运行里。毫米仍是 0.01 mm/像素的占位值，电机转了不等于已经标定或已经清洗。

```text
摄像头或图片
→ 质量检查
→ 污染掩膜、面积、中心
→ 像素路径
→ 假设毫米，再按 320 步/mm
→ 每段一条 MOVEXY（X、Y 各自最多 1600 步）
→ HELLO 得到 STEP_OK v0.3
→ 两轴同时走，READXY 到都停稳
```

协议和接线只看 [串口协议与参数](../硬件组/串口协议与参数.md)。

```text
.\.venv\Scripts\python.exe -m demo.demo_pipeline --from-camera --mode analyze --stage2-xy --arm-stage2-xy --serial-port COMx --camera-index 0
```

不发脉冲时去掉 `--arm-stage2-xy` 和 `--serial-port`。`--live` 只看画面，不能同时发步进。

| 环节 | 代码 | 交给下一环的东西 |
|---|---|---|
| 成像 | `demo/demo_pipeline.py`，相机或图片 | 一帧像素 |
| 识别 | `microcleaning/vision/` | 掩膜、面积、中心 |
| 路径 | `microcleaning/control_system/planning/` | 像素路径和 `MOVEXY` 文本 |
| 串口 | `stage2_protocol.py`、`stage2_link.py` | `HELLO` / `MOVEXY` / `READXY` |
| 执行 | `firmware/stage2-stepmotor/` | 两台 DM542 的脉冲 |

A 负责数据和标注，B 负责识别，C 负责路径和串口文本，硬件组负责 F103 固件和接线。人工标注只用来评价，不送进识别。
