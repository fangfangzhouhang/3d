# 保留的 Stage 1 喷水工程

这份代码用来比较原有喷水状态机/协议行为、保持旧工程可编译；它不是当前 XY + 泵联合运行入口。

driver_a 与 system_b 是历史目录名字，不对应当前 A/B 视觉成员，也不改变 H1/H2 分工。

- common/main.c：旧板级入口。
- driver_a/：旧 HAL、中断与串口过长行保护。
- system_b/：旧命令解析与行接收。
- ../../safety/：共享控制状态机和数据类型。
- ../../serial/：共享 MCV1 协议。
- ../../keil/f103-stage1.uvprojx：旧 Keil 工程。
- tests/：保留的 7 组 C 回归与仓库路径检查。

旧板级入口的 PB2 配置仍保留原代码，不能认为本次当前入口的常闭上拉联锁自动覆盖旧固件。没有现场核对不要烧录旧工程替换当前版本。
