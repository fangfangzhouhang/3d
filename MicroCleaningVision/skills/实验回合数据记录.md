# 实验回合数据记录技能

## 使用时机

在捕获真实 observation、动作、结果、标定记录或失败时。

## 流程

1. 读取 `project_state.yaml`、`docs/06_真实实验操作规程.md` 和 `docs/07_实验数据与回合规范.md`。
2. 在捕获前分配一个不复用的 task/episode ID。
3. 保留原始产物；将派生数据创建为独立文件；计算 SHA-256 并关联 ID。
4. 记录每个 SafetyDecision 和 ExecutionReceipt，包括 DENY/HUMAN/失败结果。
5. 为数据缺失、质量差、状态未知或物理失败编写 FailureRecord。

## 验收标准

另一名成员能够将任何指标追溯到原始产物、设置/版本、坐标 frame、实际回执和验证路径。
