# 硬件固件入口

当前硬件组只有三个责任目录。两个成员分别维护泵和运动，共同编译成一份运行程序；不是两个人轮流往同一块板烧两份程序。

| 目录 | 主责 | 输入 → 输出 |
|---|---|---|
| pump/ | H1 | 开/关输出申请 → PB0 泵控制电平；低层驱动不自行决定喷洗时间 |
| motion/ | H2 | 两轴步数、方向或名义针头偏移 → X/Y 脉冲与计数 |
| common/ | H1 默认集成主改、H2 复核 | 串口命令 + 按钮状态 + 时间 → 审核、分发、停止、回复 |

common/main.c 是当前联动固件的唯一入口。common/keil/ 是两套工程的共同编译入口，不属于第三位成员。common/compat/stage1/ 保留旧喷水工程，只用于兼容测试和历史对照；当前联动程序已经复用它的安全状态机和 MCV1 协议。
